# Rick & Morty — каталог персонажей

React-приложение по вселенной **Rick & Morty**.
Возможности:

- просмотр списка персонажей;
- просмотр страницы с деталями по конкретному персонажу;
- фильтрация списка персонажей по разным критериям;
- поиск по списку персонажей.

## Установка и запуск приложения

### Требования

- **[Node.js](http://nodejs.org/en)**: актуальная LTS-версия
- **[npm](https://www.npmjs.com/)** или **[yarn](https://yarnpkg.com/)**: пакетный менеджер

### Запуск в режиме разработки

```bash
git clone https://github.com/petr-romantsov/rick-morty.git
cd rick-morty
npm i
npm run dev
```

После запуска откройте адрес, который выведет Vite в терминале (обычно `http://localhost:5173`).

## Структура проекта

Ниже — упрощённая структура папок и назначение основных частей:

```text
src/
  app/            # корневое приложение и настройка маршрутизации
  pages/          # страницы (роуты): список персонажей, карточка персонажа, 404
  widgets/        # крупные UI-блоки (составные компоненты)
  shared/         # переиспользуемые компоненты/типы/константы/хелперы
  api/            # функции для запросов к API
  hooks/          # кастомные React-хуки (загрузка, debounce и т.п.)
  assets/         # шрифты, изображения, svg-иконки
  main.tsx        # точка входа (mount React-приложения)
```

## Технологии

- **React**: UI и компоненты приложения
- **TypeScript**: типизация и безопасная разработка
- **Vite**: быстрый dev-сервер и сборка проекта
- **React Router**: маршрутизация между страницами
- **Axios**: HTTP-запросы к API
- **Sass (sass-embedded)**: стили и удобная работа с SCSS/Sass
- **clsx**: удобное условное формирование `className`
- **react-hot-toast**: уведомления (toast) в интерфейсе
- **ESLint**: линтинг TypeScript/React-кода
- **Stylelint** (+ Vite plugin): линтинг CSS/SCSS и авто-фиксы
- **SVGR (vite-plugin-svgr)**: импорт SVG как React-компонентов
